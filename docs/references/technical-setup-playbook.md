# Technical Setup Playbook

Use this reference when reading charts, dataframe packets, and group behavior.

## Priority

Daily setup quality and location outrank group context, which outranks intraday structure, which outranks 620 timing.

## Core Reads

- Stage 1: base building, no trend yet, watch only unless using a defined reversal setup.
- Stage 2: uptrend, best long environment for VCP, breakout, pullback, and trend continuation.
- Stage 3: distribution, failed breakouts, double tops, and leader divergence matter.
- Stage 4: downtrend, avoid longs unless a specific reversal setup is forming.

## Setup Families

- VCP: volatility contracts, volume dries up, sellers disappear before breakout.
- Pullback buy: strong stock returns to support such as 20EMA/50MA/trendline on controlled volume.
- U&R: undercut prior low, reclaim quickly, selling pressure exhausts.
- Double top: second push fails at prior high, often with heavy down-volume.
- Failed base or failed breakout: should have worked but reverses quickly below pivot.
- 620: use only for timing near an already valid key level.

## Dataframe Plus Visual Rule

Dataframe values are the source of truth for exact levels. Visual review judges pattern cleanliness, trendlines, base quality, chop, and group synchronization.
