# Strategy Effectiveness Playbook

Use this reference when asking which setup family is working now.

## Evidence Inputs

- Setup outcomes: setup type, family, direction, effective date, entry, stop, exit, max R, final R.
- Recommendation outcomes: max R, max percent move, final R, days to max R, stop hit, target hit, setup violation.
- Market condition: trend, breadth, leader behavior, quick rotation, distribution, easy money, hard penny.

## Ranking Logic

Rank setup families by recent rolling-window evidence, not by theory.

Useful stats:
- sample count
- win rate
- average max R
- average final R
- stop rate
- target hit rate
- performance by market regime and theme

## Decision Use

- If a setup has positive recent final R and enough samples, it can receive more focus.
- If a setup has poor final R or frequent violations, downgrade it even if the chart pattern looks good.
- If samples are too small, use water-test exposure and keep collecting evidence.
