# Visual Review Plan

## Principle

Visual models should not scan the whole market every day. Use them for chart-pattern recognition, trendlines, group structure, and final-quality judgment.

Program and dataframe analysis are better for exact values. Visual review is better for:

- daily setup quality and chart location
- double top recognition
- double bottom recognition
- head and shoulders recognition
- VCP shape recognition
- wedge and trendline recognition
- base cleanliness
- messy chop versus constructive tightening
- group synchronization
- whether a setup looks forced
- whether a 620 reversal candidate is visually close to readiness

Review priority:

```text
daily setup quality first
group/theme behavior second
intraday setup structure third
620 readiness last
```

## Visual Review Schedule

Use visual review mainly on:

- Sunday full scan
- Wednesday midweek full scan
- major market change
- manual review request
- important trigger or violation

Normal days should usually rely on dataframe updates plus optional gallery snapshots.

## Part A: Group Gallery Review

Create gallery views by:

- theme
- industry
- supply-chain group
- sector
- commodity group
- ETF and related stocks

The group gallery model answers:

- is this group healthy?
- are stocks synchronized?
- are they basing together?
- are they hitting resistance together?
- are leaders confirming or diverging?
- is the group extended?
- is this a long group, short group, or avoid group?
- should this group be a focus this week?
- should this group be monitored next month?

Use 12-chart gallery grids for cost-effective first analysis.

## Part B: Individual Deep Review

Only use full-size individual chart review for finalists.

Individual review answers:

- what chart pattern is present?
- is the pattern clean?
- is the daily setup strong enough to care about intraday timing?
- is an intraday structure forming, such as double top, double bottom, base, failed breakout, or U&R?
- where is the natural trendline?
- where are the real support and resistance levels?
- is confirmation meaningful?
- is there a violation?
- is the setup too early, ready, triggered, or too late?
- what is the entry zone?
- what is the invalidation level?
- what exit style fits this market?
- if this is a reversal candidate, is 620 readiness worth monitoring?

## Chart Plus Dataframe

Best accuracy comes from using both:

```text
dataframe packet = exact values and objective facts
chart image = pattern, trendline, cleanliness, and context
```

The visual model should not invent exact levels when dataframe values are available. It should use dataframe values as source of truth and add visual judgment.

## Cost Control

Recommended flow:

```text
structured dataframe review
-> 12-chart group gallery review
-> select best candidates
-> individual full-size chart review
```

Do not run deep individual visual review daily unless a new decision is needed.
