# Alphaboard Docs

This folder documents the current Alphaboard direction: a trading intelligence workflow where code does objective scanning, models do review and interpretation, and the user makes the final trading decision.

## Current Decision Docs

- [strategy-intelligence-workflow.md](strategy-intelligence-workflow.md) - end-to-end workflow from data ingestion to final report.
- [implementation-roadmap.md](implementation-roadmap.md) - detailed build plan for the new research workflow.
- [market-condition-model.md](market-condition-model.md) - multi-timeframe market condition flags and strategy mapping.
- [data-model-plan.md](data-model-plan.md) - proposed tables for leaders, themes, supply chain, group relationships, focus lists, recommendations, and outcomes.
- [setup-detection-plan.md](setup-detection-plan.md) - loose first-pass setup detection and key-level scanning philosophy.
- [620-reversal-readiness.md](620-reversal-readiness.md) - 620 reversal early-warning workflow and model/program split.
- [visual-review-plan.md](visual-review-plan.md) - group gallery and individual chart review responsibilities.
- [daily-update-plan.md](daily-update-plan.md) - normal-day focus-list update flow and daily focus decision.
- [generated-artifacts-policy.md](generated-artifacts-policy.md) - repo hygiene policy for generated files.

## Core Principle

```text
Code finds possible opportunity.
Models judge quality and context.
User makes the final decision.
```
